# Teleoperation_Challenge

This project demonstrates teleoperation and simulation of dual UR3e arms with Robotiq 85 grippers. Using ROS 2, RViz, MoveIt, and Python nodes, it provides intuitive 3DOF control (X/Z/yaw) plus gesture-based gripper open/close.

---

### Install & Build

1) Prepare ROS 2 Humble:
```bash
# Source your ROS 2 environment (see official docs)
source /opt/ros/humble/setup.bash
```

2) Create/enter a Python environment:
```bash
# Using Conda
conda create -n env_6dofarms python=3.10 -y
conda activate env_6dofarms
```

3) Install dependencies:
- ROS Python and visualization (Humble):
```bash
sudo apt update
sudo apt install -y ros-humble-rclpy rviz2 robot-state-publisher joint-state-publisher
```

- Required Python packages:
```bash
pip install numpy opencv-python tflite-runtime pillow pyyaml scipy
```
- Gesture/keypoint detection:
```bash
pip install mediapipe
```

4) Build and load the workspace:
```bash
# From repo root
colcon build
source install/setup.bash
```

Note: Even if `build/` and `install/` are present, rebuilding locally with `colcon build` is recommended to match your environment.

5) Open-source packages and tools:
- ROS 2 community packages (`robot_state_publisher`, `rviz2`, `joint_state_publisher_gui`, etc.)
- UR description and MoveIt config packages
- Robotiq 85 community driver and message packages
- Referenced models/drivers:
  - Robotiq 85 gripper model/driver: `robotiq_85_gripper` (Robotiq/community resources)
  - UR arm description: Universal Robots ROS 2 Description (`Universal_Robots_ROS2_Description`)
  - UR arm driver: Universal Robots ROS 2 Driver (`Universal_Robots_ROS2_Driver`)

Note: The above resources come from official/community repositories; their versions and licenses follow each upstream repository.

## Quick Start

Use three terminals:

- Terminal 1: Launch model display (RViz)

```bash
ros2 launch dual_ur3e_description dual_ur3e_display.launch.py
```

- Terminal 2: Start end-effector command publisher (status prints and demo)

```bash
python3 scripts/endeffector_commander.py
```
Tip: RViz may not load the model correctly if only Terminal 1 runs; after starting Terminal 2 it will load properly. We keep Terminal 2 separate to monitor node state and the current motion coordinates printed in the terminal and shown in RViz.

- Terminal 3: Start teleoperation control (open camera for action/gesture recognition)

```bash
python3 scripts/teleop_endeffector_control.py
```
After starting Terminal 3, a camera window will open showing detected arm and hand skeletons. The terminal will print:
- Workspace ranges and mapping: wrist movement in image XY → arm XZ; wrist yaw → arm wrist rotation. The first fully detected arm frame is the anchor; subsequent values are relative to that initial frame.
- Gesture mapping: open palm → open gripper; closed fist → close gripper.
- Visibility hints: if keypoints or gestures are momentarily not visible, the current target holds position.

2) Safety enable/disable/E-Stop
- A green “Enable” button toggles to orange “Disable”. When enabled, you can teleoperate the arms.
  With all three terminals running and Enable active: moving your arm in the camera window moves the robot in RViz; terminal logs help you monitor each mapping step.

- A red “Estop” button immediately stops motion. While E-Stop is active, Enable is unavailable.

3) Manual reset in RViz
- A red “Reset” button resets the robot model position and clears E-Stop.

## Project Layout

- `scripts/`
  - `endeffector_commander.py`: End-effector command publishing/demo and joint-state printing
  - `teleop_endeffector_control.py`: Teleop controller; maps wrist pose to end-effector position/yaw and handles gestures
- `dual_ur3e_description/`: Dual-arm and gripper models and display launch
- `robotiq_85_*`: Robotiq 85 related packages
- `ur_*`: UR descriptions, control, and MoveIt config
- `docs/USAGE_GUIDE.md`: Additional usage guide (if present)
- `build/`, `install/`, `log/`: Generated by `colcon`

## Pre-Flight Checks

- `source` the ROS 2 environment (e.g., `/opt/ros/<distro>/setup.bash`) and this workspace (`install/setup.bash`)
- Camera/input devices work and are accessible by OpenCV (for live gesture recognition)
- Required topics/TFs are being published. Quick checks:
```bash
ros2 topic list
ros2 topic echo /joint_states --once
ros2 topic hz /joint_states
```
