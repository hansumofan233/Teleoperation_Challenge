# 双臂遥操作系统使用指南

## 系统特性

✅ **无需校准** - 手臂自然下垂即可开始操作  
✅ **3D位置控制** - X(前后), Y(左右), Z(上下)  
✅ **手势识别** - 张开手掌=开夹爪，握拳=关夹爪  
✅ **一键重置** - RViz 按钮或服务/话题触发  
✅ **噪声过滤** - 自动平滑和手势稳定化  
✅ **独立控制** - 左手控制左臂，右手控制右臂  

## 启动步骤

### 1. 启动RViz可视化
```bash
ros2 launch dual_ur3e_description dual_ur3e_display.launch.py
```

### 2. 启动命令执行器
```bash
cd /home/cnbot/Teleoperation_Challenge
python3 scripts/endeffector_commander.py
```

### 3. 启动摄像头控制
```bash
cd /home/cnbot/Teleoperation_Challenge
python3 scripts/teleop_endeffector_control.py
```

## 操作说明

### 手臂位置控制

| 你的动作 | 机械臂响应 | 说明 |
|---------|-----------|------|
| 🫱 **向前伸手** | 机械臂向前移动 | X轴正向（远离基座） |
| 🫲 **收回手** | 机械臂向后移动 | X轴负向（接近基座，但有安全限制） |
| ⬅️ **左手向左** | 左机械臂向左移动 | Y轴正向 |
| ➡️ **右手向右** | 右机械臂向右移动 | Y轴负向 |
| ⬆️ **抬起手臂** | 机械臂上升 | Z轴正向（无论手臂姿态） |
| ⬇️ **放下手臂** | 机械臂下降 | Z轴负向 |

### 夹爪控制

| 手势 | 夹爪动作 | 说明 |
|-----|---------|------|
| 🖐️ **张开手掌** | 打开夹爪 | 至少3个手指伸直 |
| ✊ **握拳** | 关闭夹爪 | 最多1个手指伸直 |

**重要**: 系统会自动过滤噪声，手势需保持约0.5秒才会触发

### 键盘控制

- **q** - 退出程序
- **s** - 保存当前画面截图
- 重置请使用 RViz Reset 按钮或 `ros2 service`/`ros2 topic`（见下文）

## 工作空间范围

- **X轴**: 0.3m ~ 0.9m (前后)
- **Y轴**: -0.4m ~ 0.4m (左右)
- **Z轴**: 0.5m ~ 1.2m (上下)

## 使用技巧

### 1. 初始姿势
- 站在摄像头前，距离1-2米
- 双手自然下垂或放在身前
- 不需要摆出特定姿势

### 2. 平滑移动
- 缓慢移动手臂，避免突然动作
- 系统会自动平滑运动轨迹
- 保持手部在摄像头视野内

### 3. 手势识别
- 手势需要清晰明确
- 保持手势约0.5秒
- 手掌完全张开或完全握拳效果最好

### 4. 左右手独立
- 左手控制左机械臂（画面左侧）
- 右手控制右机械臂（画面右侧）
- 可以单独控制一只手，也可以双手协同

### 5. 重置功能 ⭐ 新功能
- **何时使用**: 当机械臂移动到不便观察的位置时
- **如何使用**: 点击 RViz 中的 Reset 按钮，或调用服务/话题（见下文）
- **效果**: 
   - 双臂立即返回初始位置
   - 夹爪自动打开
   - 清空所有状态缓冲（包括摄像头参考锚点）
- **初始位置**:
   - 左臂: X=0.6m, Y=0.3m, Z=0.7m
   - 右臂: X=0.6m, Y=-0.3m, Z=0.7m

## 典型应用场景

### 场景1: 抓取物体
```
1. 将手移动到物体上方对应位置
   → 机械臂末端移动到物体上方

2. 张开手掌
   → 夹爪打开

3. 降低手臂高度
   → 机械臂下降

4. 握拳
   → 夹爪关闭，抓取物体

5. 抬起手臂
   → 机械臂上升，提起物体
```

### 场景2: 从异常位置恢复
```
1. 机械臂移动到不便观察的位置
   → 点击 RViz 中的 Reset 按钮（或调用服务）

2. 双臂自动返回初始位置
   → 重新开始控制

3. 继续操作
   → 手臂跟随你的动作
```

### 场景3: 双臂协同
```
1. 左手移动到左侧物体位置
   → 左机械臂移动

2. 右手移动到右侧物体位置
   → 右机械臂移动

3. 同时握拳
   → 两个夹爪同时抓取

4. 同时向中间移动双手
   → 两个机械臂将物体拿到一起

5. 如需重新调整，按 'r' 重置
```

## 故障排除

### 问题1: 机械臂不动
- 检查是否所有三个程序都在运行
- 确认手臂在摄像头视野内
- 查看终端是否有错误信息
- **使用 RViz Reset 按钮重置**

### 问题2: 手势识别不响应
- 确保手掌完全张开或完全握拳
- 保持手势至少0.5秒
- 检查手部是否被遮挡

### 问题3: 左右手对应错误
- 确认摄像头画面已经翻转（镜像模式）
- 重启teleop_endeffector_control.py

### 问题4: 机械臂抖动
- 减慢手部移动速度
- 系统会自动平滑，保持稳定约1秒

### 问题5: 机械臂位置不对劲
- **使用 RViz Reset 按钮重置到安全位置**
- 重新开始控制
- 如果问题持续，检查工作空间参数

## 安全注意事项

⚠️ **重要安全提示**:
1. 系统有工作空间限制，防止机械臂与基座碰撞
2. 首次使用时建议从小幅度动作开始
3. 观察RViz中的机械臂位置，确保安全
4. **遇到异常请使用 RViz Reset 按钮重置**
5. 紧急情况下按 'q' 键退出

## 技术参数

### 控制频率
- 视频处理: ~30Hz
- 位置更新: ~30Hz
- 手势识别: ~6Hz (带缓冲)

### 平滑参数
- 位置平滑系数: 0.3
- 手势缓冲大小: 5帧

### 映射参数
- 手臂移动范围: ±0.5m (相对肩膀)
- 映射到机械臂: 0.6m工作范围
- 高度映射: 摄像头画面上方→机械臂高位

### 初始位置
- 左臂: (0.6, 0.3, 0.7) m
- 右臂: (0.6, -0.3, 0.7) m
- 所有夹爪: 打开状态

## 自定义配置

如需调整参数，可以修改 `teleop_endeffector_control.py` 中的参数：

```python
# 工作空间范围
self.declare_parameter('workspace_x_min', 0.3)
self.declare_parameter('workspace_x_max', 0.9)
self.declare_parameter('workspace_y_min', -0.4)
self.declare_parameter('workspace_y_max', 0.4)
self.declare_parameter('workspace_z_min', 0.5)
self.declare_parameter('workspace_z_max', 1.2)

# 初始位置（用于重置）
self.INITIAL_LEFT_POSITION = np.array([0.6, 0.3, 0.7])
self.INITIAL_RIGHT_POSITION = np.array([0.6, -0.3, 0.7])

# 平滑系数 (0-1，越小越平滑但响应越慢)
self.declare_parameter('position_smoothing', 0.3)

# 手势缓冲大小 (帧数，越大越稳定但响应越慢)
self.gesture_buffer_size = 5
```

## 在 RViz 中手动重置（无需重启）

- 启动重置按钮节点：

```bash
cd /home/cnbot/Teleoperation_Challenge
python3 scripts/rviz_reset_button.py
```

- 在 RViz 中添加显示：
   - 添加一个 `InteractiveMarkers` 显示
   - 将 `Update Topic` 设置为 `/teleop_reset/update`
   - 画面中会出现一个红色“Reset”按钮，点击即可重置

- 也可以通过命令行重置：

```bash
# 调用服务方式
ros2 service call /teleop/reset_reference std_srvs/srv/Trigger {}

# 或通过话题触发
ros2 topic pub -1 /teleop/reset std_msgs/msg/Empty {}
```

说明：RViz 自带的 'r' 键仅重置“视角”，不会影响机器人状态；之前摄像头程序里的 'r' 键重置，需要摄像头窗口获得焦点才会生效。本方案将“重置参考与模型初始位置”做成 ROS 接口与 RViz 按钮，避免频繁重启。
